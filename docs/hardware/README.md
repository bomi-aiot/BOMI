# Hardware

예상 장비: Jetson Orin Nano, Raspberry Pi 5, 2D LiDAR, 카메라, IMU, 초음파 센서, 현관 센서, 온습도 센서. 핀맵과 전원 구성은 하드웨어 확정 후 기록합니다.

## 휴식·온습도 기능 기준

- 카메라는 일정 시간 이상 누움 자세를 로컬 Vision에서 판정하는 데 사용합니다. 프레임·관절 좌표·얼굴 특징은 중앙 DB로 보내지 않습니다.
- 휴식 판정 임계시간과 기상 해제 조건은 모델·설치 높이·시야각을 검증한 뒤 운영 설정으로 확정합니다.
- 온습도 센서는 단위가 명확한 `°C`, `%RH` 값을 제공하고 장치 ID·관측시각과 함께 MQTT 이벤트를 만듭니다.
- 초당 원시 측정값을 중앙 DB에 저장하지 않습니다. 최신값과 임계값 초과·의미 있는 변화 사건만 전송하며, 샘플링 주기·히스테리시스·센서 보정 기준은 하드웨어 확정 후 기록합니다.
- 센서 고장·오래된 관측·안전 조건 불확실 시 로봇은 환경 질문이나 접근을 강행하지 않고 안전한 기본 동작을 유지합니다.
