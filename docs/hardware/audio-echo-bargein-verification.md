# 에코 억제·barge-in 실기 검증 항목

> 대상: S15P11E102-205 를 실기에서 마무리하는 사람
> 관련 코드: `robot/ai_chat/src/bomi_ai_chat/audio/`, `graph/ingress.py`, `graph/output.py`
> 근거: CLAUDE.md §13(barge-in), §22 3단계, §24(미결 항목)

## 왜 이 문서가 있나

205 의 판단 로직(에코 가드, 맞장구 판별, 재생 취소, 잔여분 재큐)은 **하드웨어 없이 구현하고 검증했습니다.** 자동 테스트 20건이 그 동작을 고정하고 있습니다.

하지만 **"무엇을 에코로 볼 것인가"의 임계치와, 실제로 스피커 소리가 마이크로 되돌아오는 현상 자체는 측정해야만 정해집니다.** 그 부분이 아직 비어 있고, 이 문서가 그 목록입니다.

**이 문서의 항목이 끝나기 전에는 능동 발화(206)를 실기에서 테스트하지 마십시오.** 에코를 안 잡은 상태에서 능동 발화를 테스트하면 모든 버그 리포트가 실제로는 에코이고, 게이트 버그로 오진하면 디버깅이 지옥이 됩니다(CLAUDE.md §22 가 3단계를 4단계보다 앞에 둔 이유).

## 실기에서 해야 하는 것

### 1. 임계치 실측 — 가장 중요

두 값이 **추정치**입니다. 코드에 그렇게 적혀 있습니다.

| 상수 | 현재값 | 어디 |
|---|---|---|
| `ECHO_GUARD_SEC` | `0.3` | `policy.py` |
| `ECHO_VAD_THRESHOLD_MULTIPLIER` | `2.5` | `policy.py` |

측정 방법:

1. 로봇을 평소 사용 위치에 두고 스피커 음량을 실제 운용값으로 맞춘다
2. 로봇이 길게 말하는 동안 **아무도 말하지 않는다.** VAD 가 발화로 판정하는지 로그로 확인
   - 판정한다 → 배수를 올린다
3. 로봇이 말하는 동안 **평소 목소리로** 끼어든다. 즉시 멈추는지 확인
   - 안 멈춘다 → 배수를 내린다
4. 2와 3이 동시에 만족하는 값을 찾는다. 못 찾으면 → AEC 로 간다(아래)

### 2. AEC 를 쓸지 결정 (CLAUDE.md §24 미결)

지금 것은 **값싼 완화책**이지 음향 반향 제거가 아닙니다. 위 3번에서 "에코를 막으면 끼어들기도 못 잡는" 구간이 나오면 완화책의 한계이고, AEC 가 필요합니다.

ReSpeaker 는 하드웨어 AEC 를 지원합니다(채널 0 이 처리된 신호). `audio_io/beam_control.py` 와 함께 검토하십시오.

### 3. 원거리 마이크 성능 (CLAUDE.md §24)

**소프트웨어로 못 고칩니다.** 거실 반대편에서 한 말이 STT 에 도달하는지 일찍 확인해야 합니다. 여기서 막히면 205 가 아니라 하드웨어 배치 문제입니다.

### 4. VAD·웨이크워드 실물 연결

`audio/vad.py` 에 경계(`VoiceActivityDetector`)만 있고 구현이 없습니다.

- Silero VAD 연결 → `EchoAwareVad` 에 주입
- openWakeWord 연결
- Jetson(aarch64)에서 모델 로딩과 추론 지연 측정 — 프레임마다 도는 경로입니다

### 5. 문장 경계 중단의 체감 지연

지금은 **현재 문장을 끝으로** 멈춥니다(프레임 단위로 자르지 않음). 이유는 `audio/playback.py` 주석에 있습니다.

실기에서 "끼어들었는데 로봇이 한참 더 말한다"고 느껴지면 프레임 단위 중단을 검토하십시오. `response_shaper` 가 문장을 짧게 유지하므로 괜찮을 것으로 예상하지만, **예상이지 측정이 아닙니다.**

### 6. 맞장구 목록 보강

`policy.BACKCHANNELS` 는 지금 8개뿐이고 **상상으로 만든 목록입니다.**

CLAUDE.md §13 이 못박은 대로 실제 녹취록에서 채워야 합니다. 사투리와 개인 습관이 지배적인 영역이고, 여기서의 오탐은 **어르신이 실제로 한 말을 로봇이 무시하는 것**입니다.

### 7. `pipeline.py` 연결

아직 `pipeline.py` 가 그래프를 부르지 않습니다. 연결할 때 **재생 완료를 기다리는 구조인지 반드시 확인**하십시오. 기다리면 barge-in 이 원리적으로 불가능해집니다(CLAUDE.md §13).

- 캡처 루프와 재생이 서로 독립적으로 돌아야 합니다
- `EchoGuard` 인스턴스를 캡처 루프와 `SentencePlayer` 가 **공유**해야 합니다. 따로 만들면 가드가 동작하지 않습니다

## 완료 조건 대조

205 티켓의 완료 조건 3건에 대한 현재 상태입니다.

| 완료 조건 | 로직 | 실기 |
|---|---|---|
| TTS 재생 중 로봇이 자기 말에 멈추지 않음 | O | **미확인** (임계치 실측 필요) |
| "응/그래" 발화 시 문장을 끝까지 말함 | O | **미확인** (목록 보강 필요) |

로직은 자동 테스트로 고정돼 있고, 실기 열은 이 문서의 항목이 끝나야 채워집니다.
