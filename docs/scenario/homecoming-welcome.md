# 귀가 환영 및 맞춤 대화 시나리오

## 1차 목표 흐름

1. 현관 센서가 문 열림을 감지하고 MQTT 이벤트를 발행한다.
2. 백엔드가 이벤트를 수신하여 귀가 시나리오를 생성한다.
3. 백엔드가 로봇에 현관 이동 명령을 전달한다.
4. 로봇이 이동 결과를 보고하고 맞춤 인사를 제공한다.
5. 사용자가 STT/TTS 기반으로 로봇과 대화한다.
6. 백엔드가 대화 및 귀가 정보를 기록한다.
7. 보호자가 대시보드에서 상태와 기록을 확인한다.

초기 시연에서는 센서 이벤트, 이동 명령, 맞춤 인사 일부를 Mock으로 대체할 수 있습니다.
