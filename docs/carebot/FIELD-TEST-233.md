## 미리 알고 시작하는 제약

솔직하게 적어 둡니다. 이것들은 실패가 아니라 **범위 밖**입니다.

| 제약 | 결과 |
| --- | --- |
| 로봇 본체 미연결 | 문 앞으로 이동하는 동작을 확인할 수 없습니다 |
| EC2 에 `UPSTAGE_API_KEY` 없음 | **의미 검색이 꺼져 있습니다.** §17 의 2·10번을 잴 수 없습니다 |
| Qdrant 미배포 | 위와 같습니다. 218 MR 머지 + 배포가 선행입니다 |
| 임베딩 API 잔액 $10 | 켠 뒤에도 시연까지 아껴야 합니다. `EMBEDDING_SYNC_ENABLED` 는 켜지 마십시오 |
| 실제 어르신 아님 | 발음·리듬·사투리가 실제 사용자와 다릅니다. 여기서 모은 녹취는 **첫 근사**입니다 |

마지막 항목이 중요합니다. 개발자가 낸 목소리로 맞춘 임계치는 78세 어르신에게 맞지 않을 수 있습니다. 그 사실을 `PROGRESS.md` 에 남기고, 진짜 사용자 테스트를 별도 항목으로 세웁니다.
