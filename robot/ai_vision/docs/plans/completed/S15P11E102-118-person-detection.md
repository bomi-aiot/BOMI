# S15P11E102-118 사용자 객체 탐지

## 목표

노트북 카메라 프레임에서 YOLO11로 모든 사람을 탐지하고 OpenCV 화면에 표시하는 최소 실행 흐름을 완성한다.

## 작업 범위

- 외부 라이브러리 독립적인 사람 탐지 결과 계약
- YOLO11 모델 로딩과 person 결과 변환
- OpenCV 카메라 입력, 결과 표시, 자원 정리
- 명령행 인자와 단위 테스트
- 설치·실행·문제 해결 문서

## 제외 범위

ByteTrack, 사용자 선택, 얼굴 인식, 자세·수면 분석, 상태 머신, ROS2, 모터 및 대화 제어는 구현하지 않는다.

## 구현 단계

- [x] 탐지 결과 계약과 변환 경계 구현
- [x] 카메라·표시 adapter 및 application 흐름 구현
- [x] 명령행 진입점과 단위 테스트 구현
- [x] README와 의존성 갱신
- [x] 프로젝트 전체 검증
- [x] 실제 노트북 카메라 수동 검증

## 테스트 계획

외부 모델이나 카메라 없이 클래스·신뢰도 필터, 좌표 검증, 다중 사람 반환, CLI 범위를 단위 테스트한다. 실제 카메라는 수동 검증으로 구분한다.

## 완료 조건

단위 테스트와 정적 검사를 통과하고, 설치 환경에서 `python -m bomi_vision.main`으로 실행할 수 있어야 한다.

수동 테스트 결과 사람을 잘 탐지하였다.
