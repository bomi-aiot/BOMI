# S15P11E102-121 사용자 위치 계산 및 비전 결과 생성

## 목표

사람 탐지 목록과 프레임 크기에서 사람 수 상태와 화면 기준 사용자 위치 결과를 생성하고 실시간 디버그 화면에 연결한다.

## 입력과 출력 계약

- 입력: `list[PersonDetection]`, 양의 정수 프레임 너비와 높이
- 출력: `VisionPositionResult`
- 0명은 `NOT_FOUND`, 한 명은 `USER_DETECTED`, 두 명 이상은 `MULTIPLE_PEOPLE`
- 위치는 한 명일 때만 제공하며 다중 인물 중 특정 사람을 선택하지 않는다.

## 작업 범위

- 화면 중심 좌표, 정규화 수평·수직 오프셋 계산
- 화면 대비 바운딩 박스 높이 비율 계산
- 사람 수 상태 결과 생성
- 기존 카메라 파이프라인과 디버그 화면 연결
- 순수 계산 단위 테스트와 README 갱신

## 제외 범위

ByteTrack, Track ID, 프레임 간 사용자 유지, 실제 거리와 3차원 좌표, 카메라 보정, 상태 히스테리시스, ROS2와 로봇 제어는 구현하지 않는다.

## 계산 방식

박스 좌표를 프레임 경계로 제한한 뒤 중심점과 화면 중심 기준 `[-1.0, 1.0]` 오프셋을 계산한다. `height_ratio`는 제한된 박스 높이를 프레임 높이로 나눈 화면 내 크기 비율이며 실제 거리가 아니다.

## 테스트 계획

중앙·좌우·상하 위치, 높이 비율, 0명·1명·다중 인물 상태, 잘못된 프레임 크기와 박스, 프레임 밖 좌표 제한을 외부 장비 없이 검증한다.
