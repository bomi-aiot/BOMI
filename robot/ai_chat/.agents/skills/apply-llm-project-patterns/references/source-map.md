## Cross-source exclusions and gaps

- Exclude every notebook output cell from evidence; retain Markdown and code intent only.
- Exclude all credential values, endpoints, tokens, local absolute paths, and environment-specific identifiers.
- Exclude exact model names, chunk sizes, top-k values, retry counts, and thresholds as defaults unless target evaluation justifies them.
- Exclude notebook-only conveniences such as `%pip`, `nest_asyncio`, and synchronous UI assumptions unless the target runtime needs them.
- Exclude import-time network calls and expensive model/vector initialization from reusable server or library designs.
- Exclude graph, agent, multi-agent, and MCP layers that do not beat the simpler baseline.
- Mark LangSmith dataset/evaluator/experiment guidance as production hardening from current official documentation; the mandatory lecture files do not implement a complete evaluation pipeline.
- Mark MCP Streamable HTTP guidance as current-protocol verification; the source also contains legacy SSE examples.
