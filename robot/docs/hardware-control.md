# BOMI 하드웨어 및 이동 제어 기준

이 문서는 BOMI의 현재 차량, 구매 장비, 목표 연결 구조와 필수 안전 기준을 정리한다.

## 1. 현재 상태와 목표

| 구분 | 구성 | 상태 |
| --- | --- | --- |
| 현재 차량 | GA25-370 모터 1개 + MG996R 조향 서보 | 자동차형 조향 |
| 목표 차량 | JGB37-520 엔코더 모터 4개 + MDD10A + Pico H | 차동구동으로 개조 예정 |
| ROS 2 `core` | `keyboard_teleop`, `mock_motor_driver`, `status_publisher` | Mock 단계 |

구매 장비는 배송·세팅 예정이며 아직 장착이나 검증이 끝난 상태가 아니다. 실제 드라이버, 하드웨어 설정, 명령 타임아웃, 비상 정지와 Odometry도 구현되지 않았다.

차량을 실제로 개조하기 전에는 현재 자동차형 차량을 차동구동으로 취급하거나 제자리 회전을 구현하지 않는다.

## 2. 구매 장비

| 구분 | 장비 | 용도 |
| --- | --- | --- |
| 음성 | ReSpeaker XVF3800, 스피커, 유전원 USB 허브 | 음성 입력·방향 추정, TTS와 USB 전력 보완 |
| 현관 감지 | SNZB-04P, SNZB-03P, Zigbee USB 동글 | 문 상태와 현관 움직임을 Raspberry Pi 5로 전달 |
| 주행 | JGB37-520 12V 110RPM 모터 4개, MDD10A, Pico H, USB 케이블, IMU | 좌우 모터 제어, 엔코더·자세 측정 |
| Jetson 전원 | 4S 14.8V 2200mAh LiPo, 5A DC-DC, 5.5×2.5mm 플러그, 5A 퓨즈 3개와 홀더 | Jetson 전원 공급 |
| 모터 전원 | 3S 11.1V 2200mAh LiPo, 15A 퓨즈 3개와 홀더 | MDD10A와 모터 전원 공급 |
| 충전·보관 | IMAX B6, XT60 충전 케이블, 저전압 경보기 2개, LiPo 안전백 | 배터리 충전과 과방전·보관 안전 |
| 배선 | XT60 피그테일 3개, 16AWG 전선 3세트, WAGO 221-412·413 각 6개, 절연 테이프, 스트리퍼 | 전원 연결과 배선 마감 |

ReSpeaker의 음성 방향 정보는 거리나 정확한 좌표가 아니다. 문 센서 1개와 PIR 1개만으로 입실과 퇴실 방향을 항상 확정할 수도 없으므로 불확실한 경우 `unknown`으로 처리한다.

## 3. 목표 연결 구조

### 주행 제어

```text
Jetson ROS 2 /cmd_vel
→ Pico H
→ MDD10A
├─ 채널 1: 왼쪽 앞·뒤 모터
└─ 채널 2: 오른쪽 앞·뒤 모터

모터 엔코더·IMU
→ Pico H
→ Jetson ROS 2
→ Odometry
```

### 전원

```text
Jetson 전원:
4S LiPo → 5A 퓨즈 → DC-DC → Jetson

모터 전원:
3S LiPo → 15A 퓨즈 → MDD10A → 모터 4개
```

Jetson과 모터의 양극 전원은 분리한다. Jetson–Pico–MDD10A 제어 신호는 기준 전압을 공유해야 하므로 신호 GND 연결을 확인한다.

### 현관 센서

```text
문 센서 + PIR
→ Zigbee USB 동글
→ Raspberry Pi 5
→ MQTT·백엔드
```

## 4. 제어 원칙

`geometry_msgs/Twist`의 표준 의미를 유지한다.

- `linear.x`: 전후 목표 선속도
- `angular.z`: 목표 각속도

현재 자동차형 차량에서는 `linear.x == 0`일 때 모터를 정지하고 조향을 중앙으로 복귀시킨다.

목표 차동구동 차량에서는 `linear.x`와 `angular.z`를 좌우 바퀴 목표 속도로 변환한다. 이 값을 PWM에 직접 복사하지 않고 최대 속도, 가감속 제한과 모터 방향 설정을 적용한다.

ROS 2 노드, 명령 변환, 안전 정책, Pico 통신과 하드웨어 드라이버를 분리한다. 관련 설정과 launch 파일은 `robot/ros2_ws/src/core/` 패키지가 소유한다.

## 5. 필수 안전 기준

- MDD10A는 모터 전원 역극성 보호가 없으므로 전원 연결 전 극성을 측정한다.
- 모터 2개를 한 채널에 연결하면 전류가 합산된다. 정지전류는 데이터시트 또는 전류 제한 장비로 확인하고 MDD10A의 채널당 10A 연속 정격을 넘지 않는지 검증한다.
- Jetson의 정확한 보드 모델과 입력 전압을 확인한 뒤 DC-DC 출력과 플러그 중심 극성을 측정한다.
- 구매한 5A·15A 퓨즈는 임시값이다. 실제 소비전류와 배선 정격을 확인해 확정한다.
- 퓨즈는 배터리 양극 가까이에 설치하고 전원이 연결된 상태에서 배선을 바꾸지 않는다.
- 시작, 종료, 예외, 통신 끊김과 명령 타임아웃에서는 모터 PWM을 0으로 만든다.
- 잘못된 명령, 저전압, 엔코더 이상과 과전류 징후는 제한하거나 정지한다.
- 전진과 후진을 바꿀 때는 정지 구간과 가감속 제한을 둔다.
- LiPo는 셀 수에 맞는 밸런스 충전을 사용하고 충전 중 방치하지 않는다.
- 저전압 경보기는 자동 차단 장치가 아니므로 소프트웨어 저전압 정지를 별도로 구현한다.

## 6. 배송 후 확인 순서

1. 부품 모델, 수량, 손상과 커넥터 규격을 확인한다.
2. 배터리 없이 배선, 극성, 퓨즈 위치와 공통 GND를 검토한다.
3. DC-DC를 Jetson과 분리한 상태에서 출력 전압과 극성을 설정한다.
4. Jetson, USB 허브, ReSpeaker와 스피커를 하나씩 연결한다.
5. Pico의 통신과 watchdog, 시작 시 PWM 0을 확인한다.
6. 바퀴를 띄우고 모터 한 개씩 낮은 PWM으로 방향·전류·엔코더를 시험한다.
7. 모터별 전류와 채널 합산 전류가 안전한지 확인한 뒤 좌우 두 개씩 묶어 시험한다.
8. 바퀴 지름, 좌우 바퀴 간 거리, 엔코더와 IMU를 측정해 Odometry를 보정한다.
9. 문·PIR 센서를 설치 위치에서 반복 시험해 누락과 지연을 확인한다.

과열, 냄새, 소음, 진동이나 큰 전압 강하가 발생하면 즉시 전원을 차단한다.

## 7. 구현 전에 확정할 값

- Jetson 보드 모델, 입력 전압·극성과 최대 소비전력
- 모터 정격·정지전류, 엔코더 전압·핀맵·펄스 수
- Pico 핀맵, 통신 형식, 명령 주기와 watchdog 시간
- IMU와 Zigbee 동글의 정확한 모델
- 바퀴 지름과 좌우 바퀴 간 거리
- 최대 속도, PWM, 가감속과 방향 전환 제한
- 퓨즈, 배선과 커넥터 정격
- 저전압, 통신 끊김과 비상 정지 조건

확인되지 않은 값을 추측해 하드코딩하지 않는다.
