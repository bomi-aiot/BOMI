BOMI API 문서

BOMI API·메시지 계약

서비스 간 계약을 여기서 전부 찾을 수 있습니다. HTTP 는 OpenAPI, 그 외 프로토콜은 AsyncAPI 로 관리합니다.

문서 열람

구분문서담은 내용
HTTP API Swagger UI 로봇·AI 채널, 가디언웹 채널, AI 서비스 계약
Event API MQTT 계약 IoT 이벤트, 로봇 명령·상태·결과
Streaming API WebSocket 계약 아직 구현체가 없습니다

브라우저에서 되는 것과 안 되는 것

Swagger UI 의 Try it out 은 켜져 있습니다. 로봇·가디언웹 채널 API 는 브라우저에서 바로 호출해 응답을 볼 수 있습니다. 실제 데이터가 바뀝니다. 쓰기 메서드는 무엇을 건드리는지 확인하고 누르십시오.

(계약·미구현) 이 붙은 AI Vision·대화음성 스펙은 켜져 있어도 호출되지 않습니다. 서버 주소가 localhost 이고 구현체도 아직 없습니다.

MQTT 와 WebSocket 은 브라우저에서 발행·구독 시험을 할 수 없습니다. HTTP 가 아니기 때문이며, 두 페이지는 계약 열람 전용입니다. 실제 송수신은 MQTT 클라이언트나 로봇 코드로 확인하십시오.

계약을 바꿀 때

스펙 원본은 모두 backend/src/main/resources/static/openapi/ 에 있습니다. 변경 절차와 새 스펙을 추가할 때 함께 고쳐야 할 파일 목록은 저장소의 docs/api/README.md 와 backend/CLAUDE.md 에 있습니다.
