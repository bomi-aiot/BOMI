AsyncAPI · 아직 스펙이 없습니다

아직 구현체가 없습니다.

`spring-boot-starter-websocket` 의존성은 들어와 있지만 핸들러·설정·엔드포인트가 아직 없어 wss://i15e102.p.ssafy.io/api/v1/ws 는 존재하지 않습니다. 지금 접속하면 연결되지 않습니다.

이 페이지는 스트리밍 기능이 붙을 자리를 미리 잡아둔 것입니다. 실제 메시지 계약은 스트리밍 구현 티켓에서 bomi-websocket.asyncapi.yaml 로 작성하고, MQTT 와 같은 방식으로 여기에 렌더링합니다.

자리를 미리 잡아둔 이유

규칙이 없으면 다음 사람은 마크다운을 하나 더 만듭니다. MQTT 계약이 지금 겪고 있는 문제가 정확히 그것입니다 — 문서가 코드 어딘가에 흩어져 있고, 최신인지 확인할 방법이 없습니다. 경로와 네이밍을 먼저 정해두면 스트리밍을 만드는 사람이 "어디에 무슨 이름으로 쓰지"를 고민하지 않아도 됩니다.
